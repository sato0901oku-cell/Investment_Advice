# 記録フォルダ案内

このフォルダは、完了済みの作業、過去の試験、旧仕様の記録を保管する。

- 記載されたキャラクター数、背景数、セーブ数、画面構成は記録当時の値である。
- 現行仕様の判断には`../プロジェクト設定.md`と`../技術仕様・保守ガイド.md`を使用する。
- 記録は原則として当時の内容を維持し、現在値へ書き換えない。
- 通常の現行仕様・コード検索には含めず、現行資料とコードだけでは過去の理由を判断できない場合に限って対象を絞って参照する。

## 内容

- `Git導入前の主要変更履歴.md`：基準コミット`60c481f`までの主要な実装・仕様変更。凍結資料であり、以後の通常変更はGitコミットへ記録する。
- `臨時_アドベンチャーモード大規模強化_合意内容.md`：大規模強化の計画前に固定した合意と段階案。現行仕様は現役資料へ反映済みであり、保管期間後にこの記録を削除しても仕様判断には影響しない。
